🤖 Android 限定

用 GKD 自動關閉
icash Pay 活動廣告

使用本地「應用規則」精準點擊首頁廣告右側的關閉按鈕，不用座標、不套用到其他 App，也不會點擊付款或授權功能。

前往 GKD 官方 GitHub Releases 直接查看規則
先看相容性：目前已在 Samsung Galaxy Z Flip7 展開後的主螢幕驗證成功；Flip7 封面小螢幕目前無法自動觸發，請勿把本規則視為封面螢幕支援方案。
① 安裝與權限 ② 本地訂閱 ③ 完整規則 ④ 安全與測試

① 安裝 GKD 與必要權限

  1. 只從官方來源下載：前往 GKD 官方 GitHub 專案，再從 Releases 下載最新版 APK。不要安裝來路不明、遭重新打包的 APK。
  2. 允許安裝 APK：如果 Android 阻擋安裝，請暫時允許目前使用的瀏覽器或檔案管理器「安裝未知應用程式」。安裝完成後可將這項權限關閉。
  3. 啟用無障礙服務：開啟 GKD，在首頁按下無障礙權限旁的「授權」，到 Android 設定中允許 GKD 無障礙服務。沒有這項權限，GKD 無法讀取或點擊畫面節點。
  4. Shizuku 非必要：這條規則在主螢幕依靠 GKD 無障礙服務即可運作，不需要為它另外安裝或授權 Shizuku。

GKD 是 Android 工具，iPhone／iOS 不適用。不同品牌與系統版本的設定名稱可能稍有差異。

② 建立本地「應用規則」

  1. 開啟 GKD，依序進入：首頁 → 訂閱 → 本地訂閱 → 應用規則。
  2. 按右上角的新增按鈕；不同版本可能顯示為「＋」或「新增應用規則」。
  3. 複製下一節的完整 JSON5，貼入編輯器。請從最外層的 { 一直到最後一個 } 全部貼上。
  4. 儲存後確認清單出現 icash Pay，並確認「啟動廣告－自動關閉」規則組保持啟用。
  5. 不要貼到「全域規則」。這份內容是完整的應用規則，最外層已使用 icash Pay 套件名稱限制作用範圍。

③ icash Pay 應用規則

這是應用規則，不是全域規則。最外層 id 固定為 tw.com.icash.a.icashpay，只會在 icash Pay 中啟用。

JSON5｜完整複製後貼入「應用規則」
{
  id: 'tw.com.icash.a.icashpay',
  name: 'icash Pay',
  groups: [
    {
      key: 0,
      name: '啟動廣告－自動關閉',
      desc: '僅作用於 icash Pay 主螢幕啟動流程，精準匹配活動廣告右側的關閉容器。',
      activityIds: [
        'tw.net.pic.m.wallet.activity.WelcomeActivityV3',
        'tw.com.icash.icashpay.framework.page.splash.SplashActivity',
      ],
      matchRoot: true,
      fastQuery: true,
      forcedTime: 12000,
      rules: {
        key: 0,
        matches: '[vid="bottom_view"] > [vid="close"] > @[vid="container"][clickable=true] > [vid="label"][text="關閉"][visibleToUser=true]',
        action: 'clickNode',
        actionMaximum: 1,
        resetMatch: 'app',
      },
    },
  ],
}

選擇器在做什麼？

bottom_view → close → container → label「關閉」 必須同時成立。符號 @ 代表實際點擊可點擊的 container，不是只含文字但不一定能點的標籤節點。

④ 安全邊界

✓ 只限定 icash Pay

套件名稱及啟動 Activity 都已限制，規則不會跑到其他銀行、錢包或購物 App。

✓ 四層節點結構

不只匹配「關閉」兩個字，還要求廣告底欄、close 區塊、可點擊容器及可見標籤全部吻合。

✓ 不使用座標

依無障礙節點點擊，不會因螢幕尺寸、縮放或折疊比例改變就把固定座標送到錯誤位置。

✓ 不改變顯示偏好

本規則只點右側「關閉」，不點左側「今日不再顯示」，也不會碰付款、登入、儲值、轉帳、乘車碼或確認按鈕。

無障礙權限很強大：請只加入自己理解、來源可信的規則。不要為了方便改成全域 [text="關閉"]，也不要加入模糊的確認文字或固定座標。

⑤ 測試方式

  1. 確認 GKD 無障礙服務、icash Pay 應用規則及規則組都已啟用。
  2. 在最近使用的 App 畫面中滑掉 icash Pay，讓它完全關閉。
  3. 將 Flip7 完全展開，從主螢幕圖示冷啟動 icash Pay。
  4. 活動廣告出現後等待幾秒；規則應自動點擊右側「關閉」。
  5. 第一次未成功時，先重新確認權限與規則開關。不要立刻把選擇器改寬；應擷取 GKD 快照或匯出日誌，再依實際節點診斷。

⑥ 失效、停用或移除

icash Pay 更新後失效

App 改版可能更換 Activity 或資源 ID。規則若突然不動，先停用它，再用 GKD 擷取新快照，不要改成更模糊的全域文字規則。

暫時停用

進入「首頁 → 訂閱 → 本地訂閱 → 應用規則 → icash Pay」，關閉「啟動廣告－自動關閉」規則組。

停用或移除

在 icash Pay 應用規則頁使用右上角選單刪除本地規則；如果完全不再使用 GKD，也可先關閉 GKD 無障礙服務，再解除安裝。
