# kuies.tw Short URL 擴充套件圖示 v1.6.6

請產生一張適合 Chrome Web Store 的正方形應用程式圖示。

視覺概念：
- 可愛、乾淨、友善的扁平向量插畫
- 中央是一個「短網址小精靈」：兩個互相扣住的圓潤鏈結，形成簡潔、容易辨認的短網址／連結符號
- 鏈結帶有非常簡單的小笑臉，旁邊有一顆小閃光，呈現「清理後變乾淨、縮短完成」的感覺
- 保留舊版的青藍色與薄荷綠意象，但造型更圓潤可愛

配色：
- 背景使用柔和但飽和的珊瑚橘到蜜桃橘漸層，絕對不要黑色、深黑、純白或接近白色背景
- 主體使用青藍色、湖水綠與少量奶油黃色點綴
- 邊緣清晰、對比足夠，縮小到 16×16 仍能辨認

構圖與限制：
- 1:1 正方形
- 圓角方形 app icon 構圖，但圖像本身鋪滿整個正方形，不要透明背景
- 中央主體占畫面約 65%，四周保留安全邊界
- 不要任何文字、英文字母、網址、Threads 或 Instagram 商標
- 不要照片感、3D 寫實、複雜陰影、黑色外框、白色大面積底色
- 使用簡潔幾何形狀，適合小尺寸 Chrome 擴充圖示
