# kuies.tw Short URL 隱私權政策

最後更新：2026-06-15

kuies.tw Short URL Chrome 擴充的單一用途，是在使用者主動縮短網址，或在 Threads／Instagram 複製分享連結時，移除常見追蹤參數並建立 u.kuies.tw 短網址。

## 收集與傳輸的資料

擴充只會在使用者手動點擊縮短功能，或啟用自動模式並在支援網站複製連結時，將該網址傳送到 https://u.kuies.tw/api/public/shorten 以建立短網址。

服務端會儲存原始網址、短碼、建立時間、更新時間、點擊次數與基本伺服器請求紀錄，以提供短網址跳轉、濫用防護與維運除錯。

## 剪貼簿與網站內容

擴充使用剪貼簿權限是為了讀取使用者要求縮短的剪貼簿網址，並將建立好的短網址寫回剪貼簿。

擴充不會讀取或上傳非網址內容；自動模式僅在 Threads／Instagram 頁面偵測到分享網址時處理該網址。

## 資料使用與分享

資料僅用於提供短網址、追蹤參數清理、點擊跳轉、防濫用與服務維運。

不出售資料，不用於廣告投放，不與第三方分享，除非法律要求或維護服務安全所必須。

## 遠端程式碼

擴充不執行遠端程式碼；所有擴充程式碼均包含在安裝套件中。擴充會呼叫 u.kuies.tw API 以建立短網址。

## 資料刪除

若需要刪除由此服務建立的短網址資料，請聯絡服務維護者處理。
